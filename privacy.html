プライバシーポリシー

本ツール（もちもち実験室 動画アップロードツール）は、チャンネル運営者本人が自分のYouTubeチャンネルへ動画をアップロードするための個人用ツールです。

1. 取得する情報

Googleアカウントの認証情報（アクセストークン・更新トークン）と、自分のチャンネル名・チャンネルIDのみです。

2. 利用目的

運営者自身のチャンネルへの動画アップロードと、サムネイルの設定のためだけに使います。

3. 保存場所

トークンは運営者のPC内にのみ保存し、外部のサーバーへ送信・共有しません。

4. 第三者への提供

行いません。

5. 利用の停止・削除

PC内のトークンを削除するか、Googleアカウントのアクセス権の設定から取り消すことで、いつでも停止できます。

6. YouTube API サービス

本ツールは YouTube API サービスを利用しています。利用にあたっては YouTube利用規約 と Googleプライバシーポリシー が適用されます。

7. お問い合わせ

YouTubeチャンネル「もちもち実験室」の概要欄からご連絡ください。

Privacy Policy (English)

This tool is used only by the channel owner. It accesses only the owner's OAuth tokens and own channel name/ID, solely to upload the owner's videos and set thumbnails. Tokens are stored only on the owner's PC and are never sent to or shared with any third party. Access can be revoked at any time at Google Account permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
