もちもち実験室 動画アップロードツール

このツールは、YouTubeチャンネル「もちもち実験室」の運営者が、自分で制作した思考実験の解説動画を、自分のチャンネルへアップロードするためだけに使う個人用ツールです。

  • 利用者は、チャンネル運営者本人1名のみです。一般向けのサービスではありません。
  • YouTube Data API を使い、動画のアップロード（videos.insert）、サムネイルの設定（thumbnails.set）、自分のチャンネル情報の確認（channels.list）だけを行います。
  • 取得した情報を第三者に提供することはありません。詳しくはプライバシーポリシーをご覧ください。

About (English)

A private, single-user tool used only by the owner of the YouTube channel "もちもち実験室" (Mochimochi Lab) to upload their own educational videos to their own channel via the YouTube Data API (videos.insert, thumbnails.set, channels.list). It is not offered to other users.
